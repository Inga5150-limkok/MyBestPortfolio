# Bai Inga Tomayor Kamara | Portfolio

Welcome to my portfolio website. This project is a personal portfolio built with HTML, CSS, and JavaScript to showcase my background, experience, projects, certifications, and contact information in a modern and interactive way.

## Overview

This portfolio includes:
- Dark and light mode
- Responsive navigation
- Loading screen
- Scroll-reveal animations
- Back-to-top button
- Toast notifications
- Skills and project filtering
- Image gallery with viewer
- Print-friendly CV/resume section
- Experience timeline
- Certificates section
- Testimonials
- Functional contact form that opens the visitor's email client
- OpenStreetMap location section
- Blog/articles section
- Multimedia page for local audio and video
- Social links

## Features

The site is designed to feel polished, professional, and easy to navigate on both desktop and mobile devices. It combines storytelling, portfolio presentation, and personal branding into a single static website.

## Contact Form

The form is configured to open the visitor's default email client and prepare a message to:

- `tomayoringa@gmail.com`

This is ideal for a static portfolio site. If you want true form submission with server-side handling, you can connect it later to a backend or a third-party form service.

## Local Development

To run this project locally:

1. Clone the repository.
2. Open the project folder in a code editor.
3. Start a local web server, or simply open `index.html` in a browser.
4. Update the content, images, and media with your own information and materials.

For example, if you are using VS Code, a live preview extension or local server can make development easier.

## Deployment

- Any other static hosting provider

## Customization

To personalize the portfolio:
- Update your name, bio, and experience in the HTML content
- Replace placeholder media and images with your own files
- Modify colors, typography, and layout in the CSS
- Adjust animations and interactions in the JavaScript
